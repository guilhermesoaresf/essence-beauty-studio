# Essence Beauty Studio

![Essence Beauty Studio social preview](./public/og.png)

Concept website for a fictional beauty studio, created as a collaborative frontend project.

> Essence, its professionals, testimonials, address, prices, and booking flow are fictional. The scheduling form is a local demonstration and does not send or store personal data.

## Highlights

- Multi-page responsive experience built with Astro
- Editorial interface styled with Tailwind CSS
- Accessible desktop and mobile navigation
- Service catalog with reusable components
- Client-side form validation with Zod
- Demonstration booking flow with no external data transmission
- Optimized local image assets and static production output

## Tech stack

- Astro 7
- Tailwind CSS 4
- JavaScript and TypeScript
- Zod
- Lucide icons

## Run locally

Requires Node.js 22.12 or newer.

```bash
npm install
npm run dev
```

The development server will print the local URL in the terminal.

## Quality checks

```bash
npm run check
npm run build
```
